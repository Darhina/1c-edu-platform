## 🏛 Паспорт программы

- **Направление:** Практикум разработки прикладных решений на платформе «1С:Предприятие 8.3»
- **Целевая аудитория:** 17 – 25 лет (студенты СПО и вузов любого направления подготовки без опыта программирования)
- **Трудоемкость:** **24 академических часа** (6 ч лекций, 16 ч лабораторных практикумов, 2 ч итоговой аттестации/консультаций)
- **Форма итоговой аттестации:** Презентация и защита разработанных прикладных конфигураций 1С
- **Документ:** Сертификат об освоении дополнительной общеобразовательной программы установленного образца

## 🚀 Запуск проекта

### Локальный запуск на компьютерах студентов (при сбоях сети / без интернета)
Платформа сохраняет **100% функциональности без подключения к интернету**. Все ответы на тесты, галочки чек-листов лабораторных работ, конспекты и код сохраняются в `LocalStorage` браузера студента.

**Быстрый запуск в Windows:**
Просто дважды кликните по файлу **`start-local.bat`** в папке проекта. Он сам проверит зависимости и откроет сайт в браузере!

Или через командную строку:
```bash
npm install
npm run dev
```
Платформа будет доступна по адресу `http://localhost:5173`.

Для автономной демонстрации готового продакшн-билда:
```bash
npm run build
npm run preview
```

## 💡 Уникальные интерактивные модули платформы

1. **⚡ Интерактивная песочница кода (1C Code Playground)**  
   Встроенный в браузер эмулятор языка 1С! Студент может запускать реальные конструкции (`Сообщить`, `Если`, `Для Каждого`, математику, обработку строк и дат) прямо в браузере без необходимости запуска Конфигуратора.
2. **🖥 Интерактивный макет «Конфигуратора 1С 8.3»**  
   Живое Дерево метаданных: кликайте на Подсистемы, Справочники, Документы, Регистры и Отчеты — правая панель отображает реальную Палитру свойств, типы реквизитов и табличные части объекта.
3. **📖 Синтакс-помощник (F1)**  
   Интерактивный справочник по методам и операторам с поиском, категориями и примерами кода с кнопкой «Копировать». Доступен по нажатию клавиши `F1` в любой момент!
4. **📊 Интерактивные визуальные схемы:**  
   - Трехуровневая модель «Клиент – Сервер 1С – СУБД/1CD».
   - Жизненный цикл документа от черновика до проведения.
   - Демонстратор срезов периодического регистра цен («СрезПоследних»).
   - 4-шаговый пайплайн генератора отчетов СКД.
5. **🏆 Банк 6 отраслевых проектов для защиты**  
   - 1. Фитнес-клуб (абонементы и журнал визитов);
   - 2. Автосервис / СТО (заказ-наряды и нормо-часы механиков);
   - 3. Учебная библиотека (книжный фонд и читательские билеты);
   - 4. Интернет-магазин (заказы, складские остатки и маржинальность);
   - 5. Техподдержка вуза (парк техники и заявки преподавателей);
   - 6. Образовательные курсы (учебные группы, посещаемость и договоры).
6. **🎓 Генератор именного Сертификата установленного образца**  
   Ввод ФИО студента, официальные реквизиты, подпись разработчика программы и экспорт в PDF / печать с конфетти!
